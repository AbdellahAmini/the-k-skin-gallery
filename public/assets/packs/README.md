# Photos des packs

Déposez ici une image WebP par pack. Le nom doit correspondre exactement à son URL :

`ksg-pack-01.webp` à `ksg-pack-20.webp`.

Chaque page de pack utilise déjà `/assets/packs/ksg-pack-XX.webp`. La photo apparaît après l’avoir ajoutée ici et actualisé la page ; en attendant, un emplacement illustré est affiché. Privilégiez une image carrée ou presque carrée, avec tous les produits visibles et de l’espace autour. Un fond clair convient à la Gallery.

Ne changez pas le nom des fichiers sans modifier aussi le champ **Image (URL)** du pack dans l’administration.
